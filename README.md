# 真实星空观测台

真实星空观测台是一个根据观测地点、日期和时间实时展示天空变化的交互式星图工具，可以查看恒星、星座、银河、深空天体、太阳、月亮、行星以及中国传统星官。

## 快速开始

1. 确保 `index.html` 和 `assets` 文件夹位于同一目录。
2. 双击 `index.html`，即可在浏览器中打开星空观测台。
3. 使用页面中的地点、日期、时间和显示控制项开始观测。

运行本项目不需要安装依赖，也不需要启动本地服务器。复制或移动项目时，请同时保留 `index.html` 和 `assets` 文件夹，否则页面可能无法正常加载。

## 使用方法

### 设置观测地点

在“观测地点”区域中搜索并选择城市，或直接输入纬度、经度和时区。地点改变后，星图会按照新的位置重新计算天空显示。

如果浏览器允许定位，也可以使用“使用我的位置”自动获取当前位置；定位不可用时，直接选择城市或手动填写地点即可。

### 设置观测时间

在“观测时间”区域中修改年、月、日、时和分，星图会随时间更新。也可以使用当前时间按钮，或通过增加、减少月份、日期和小时的按钮快速调整时间。

年份支持输入负数，例如 `-500` 表示公元前 500 年。调整远古或远未来日期时，显示结果用于观察天空变化趋势，不应作为精密历表使用。

### 调整星图视角

- 在星图上拖动鼠标，可以旋转观察方向。
- 使用鼠标滚轮或界面中的缩放控件，可以放大或缩小星图。
- 使用方向按钮或键盘方向键，可以平移观察区域。
- 在“视图与投影”中选择地平、赤道、黄道或银河坐标视图。
- 根据需要切换不同的天球投影。
- 使用回到默认视角等控件，可以快速恢复便于观察的视图。

“天极中轴约束”开启时，拖动星图会尽量保持当前坐标系统的极轴方向稳定；关闭后可以更自由地旋转星图。

### 控制显示内容

在“显示设置”区域中，可以按需打开或关闭以下内容：

- 恒星名称和星名显示密度
- 西方星座、星座连线和星座名称
- 中国传统星官、二十八宿和传统天区
- 赤道网、黄道、地平线等参考线
- 银河
- 太阳、月亮和行星
- 深空天体
- 天体信息浮窗

还可以调整星等显示范围、恒星大小以及其他星图显示选项。关闭不需要的图层，有助于在目标较多时保持星图清晰。

### 搜索和查看天体

使用搜索框输入天体名称，可以快速定位恒星、星座、行星或深空天体。点击星图中的目标后，可以查看简要浮窗和更详细的信息。

## 功能概览

- 根据地点、日期和时间显示当地天空
- 查看真实恒星、星座、银河和深空天体
- 显示太阳、月亮和主要行星的位置
- 对照西方星座和中国传统星官体系
- 切换坐标系统和天球投影
- 调整图层、星等、标签和参考线
- 搜索天体并查看相关信息
- 支持中文和 English 界面

## 数据与精度说明

项目使用本地数据和本地运行资源，打开页面后不依赖网络服务。固定星空数据以 J2000 为基础，显示时会根据日期进行轻量岁差转换；太阳、月亮、月相和行星使用适合星图展示的计算模型。

本项目用于学习、天文文化展示和一般观测准备，不是科研级天体测量软件。当前未提供完整的恒星自行、章动、大气折射、地形地平线、天气、光污染和月光天光修正。行星位置属于近似计算，远离常用日期范围时只适合观察运动趋势。

中国传统星官和传统天区用于现代可视化与文化比较，边界和呈现方式不代表唯一的历史复原结论。
