# 真实星空观测台 4.8

本版严格以用户提供的 v4.0 为代码与星图画布基线。Canvas 尺寸计算、天然投影比例、初始完整视图、原有拖动方向、14 种投影和 4 种坐标系统均保留 v4.0 行为；修改集中在左侧菜单、极区异常跳变保护、方向标识生命周期、紫微垣几何、边界可见度、统一配置、城市搜索、工具位置、坐标系统匹配的重置视图和说明文档。

> 中文显示说明：部分中国星官、星名和传统天区的上游资料采用繁体字。本版本已将面向用户显示的中文统一转换为简体字；仅转换文字，不修改恒星坐标、星官连线、目录编号或区域几何。

## v4.8 新增

- 中西体系同时显示时，对端点一致的公共线段采用屏幕空间双轨偏移：西方线和中国线分别向两侧轻微错开，普通线段保持原位；偏移仅影响绘制，不修改真实坐标。
- 中国星官组合模式默认线宽调整为 `0.98 px`、透明度 `0.68`，保持橙色清晰可见。
- 新增 `assets/data/culture-notes.js`，独立维护重要恒星所属西方星座和中国星官的简短文化说明。文化说明与天文目录分离，不修改原始星表。

## 使用
完整解压后直接双击 `index.html`。不要只复制 `index.html`，它需要同目录下的 `config.js` 与 `assets/`。浏览器定位在 `file://` 下可能受限；需要定位时，在项目目录运行：

```bash
python -m http.server 8000
```

然后打开 `http://127.0.0.1:8000/`。

## 本版关键规则

- 星图画布：沿用 v4.0，不使用后续版本的强制铺满、横向拉伸或新适配算法。
- 菜单：标题、语言、星空体系、地点、时间、投影、坐标系统、图层、视图工具、选中天体和当前状态统一位于左侧 Panel。
- 星图表面：右上角只显示“地点 · 当地日期时间”；地平初始完整视图另显示 `E/S/W/N`。
- 方向标识：首次进入或点击“重置视图”后显示；用户第一次拖动或缩放后隐藏，不再动态跟随。
- 拖动：保留 v4.0 原生方向。新增保护只在高纬中心出现异常大角度跳变时限幅，不替换正常拖动。
- 紫微垣：按紫微右垣与紫微左垣真实墙线顺序闭合，并处理跨越 0°/360°；仍属于现代数字化复原，不是法定历史边界。
- 数据：保留 v4.0 的全部 13 组运行数据和字段；为避免重复，只在 `assets/data/preloaded-data.js` 保存一份运行副本。
- 重置视图：不会改变当前坐标系统。地平坐标按当前地点与时刻重新计算本地天空中心；赤道、黄道和银河坐标读取各自的配置中心与缩放。

## 修改外观
打开 `config.js`。文件内有详细中文注释，可配置主题、菜单宽度、恒星、星座、星官、IAU 边界、中国传统天区、行星、标签、交互阈值和各坐标系统的重置视图。修改后刷新页面即可。
