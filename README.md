# 真实星空观测台

真实星空观测台是一个完全本地运行的浏览器天文馆。项目使用真实恒星目录、西方星座、中国传统星官、银河轮廓、深空天体和太阳系数据，根据观测地点、IANA 时区与 UTC 时刻显示当前天空。

它适合肉眼认星、天文文化比较、天球坐标教学和一般观测准备；不定位为科研级天体测量、精密历表或望远镜控制软件。

## 核心功能

- 真实地点和真实时间驱动的本地天空显示。
- 中文和 English 双语界面。
- 西方星座、中国星官、两者同时显示三种星空体系。
- 14 种天球投影和 4 种坐标系统：地平、赤道、黄道、银河。
- 可调星等阈值、恒星大小、网格、黄道、天赤道、地平线、银河、深空天体和日光背景。
- 太阳、月球和主要行星的本地图层、点击拾取和信息框。
- 中国传统天区、二十八宿层级和主题天区的示意显示。
- 核心运行资源本地打包，不依赖 CDN。

## 使用说明

最简单的使用方式是直接打开根目录下的 `index.html`。项目的第三方库和运行数据都在本地，星图、地点输入、时间控制、投影切换、图层开关、搜索和 debug 均可离线使用。浏览器定位功能在 `file://` 下可能被限制；如果“使用我的位置”不可用，可以手动选择城市，或在项目根目录运行一个本地静态服务器后再打开页面。

左侧菜单用于控制星图。`观测地点` 可通过城市搜索、经纬度输入或“使用我的位置”设置；选择城市后会同步经纬度、IANA 时区和星图。`观测时间` 外观看起来是一个完整时间框，内部可分别编辑年、月、日、时、分；点击字段后可直接输入数字，按 Enter 提交；年份输入负号表示公元前，例如 `-500`。字段聚焦时可用上下键即时调整当前字段并自动进位退位，也可使用 `−1月 / −1天 / −1时 / +1时 / +1天 / +1月` 或任意步长控件。

`视图与投影` 可切换地平、赤道、黄道、银河坐标视角和不同天球投影；时间或地点变化后会按当前坐标视图刷新，不重置当前缩放。`显示设置` 控制恒星名称、星座/星官、网格、黄道、天赤道、地平线、银河、行星、深空天体和浮窗。点击星体可查看精简浮窗和左侧详细信息；天体搜索可用于快速定位对象。

左上角 `DBG` 是调试面板，用于排查布局、数据加载、时间输入、skyview、redraw 和行星计算状态；普通使用时可以关闭。远古或远未来日期允许输入，但当前项目没有完整岁差、章动、恒星自行和高精度行星历表，相关显示属于近似天文馆效果，不等同于科研级古天文历表。

## 项目结构

```text
src/        项目源码：TypeScript 入口、配置、样式和运行数据入口。
assets/     项目构建产物：app.css 和 app.js。
vendor/     浏览器直接加载的固定版本第三方库和外部参考资料。
licenses/   第三方许可证原文。
docs/       架构、构建、数据来源和第三方声明文档。
```

## 主要特性

- 内部统一保存 UTC 瞬时，界面按观测地 IANA 时区显示当地时间。
- 地点切换保持同一个绝对时刻，不把旧地点的当地时间误解为新地点时间。
- 投影和坐标系统独立保存视角，切换语言、体系或图层不会重置地点、时间和缩放。
- 中国星官、传统天区和行星图层使用项目自定义覆盖层，与 D3-Celestial 的基础星图协同绘制。
- 重要恒星信息框可显示中西文化说明，文化文字与天文目录分离维护。

## 数据来源和依赖

项目使用本地固定版本的 D3 3.5.17、d3-geo-projection、D3-Celestial 0.7.35、Luxon 和 tz-lookup。第三方库保存在 `vendor/`，运行数据以分类 JS 分片形式保存在 `src/data/`，由 `src/data/loader.js` 注册并兼容本地直开。

数据来源说明见 `docs/DATA_SOURCES.md`，第三方和许可证说明见 `docs/THIRD_PARTY_NOTICES.md`，许可证原文保存在 `licenses/`。

## 科学限制

本项目用于教育和一般天文馆式显示，不提供科研级天体测量、任意历元恒星自行传播、完整岁差章动模型、大气折射/消光、本地地形地平线、天气、光污染、月光天光或 JPL 级行星历表。

中国传统天区和战场主题区域是用于比较和教学的现代可视化复原，不是唯一的历史法定边界。
